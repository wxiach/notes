# 会计基础

> 本章对应教材第二章。会计要素是会计核算对象的具体分类，是设置账户和编制报表的基础；会计等式则揭示了各要素之间的数量关系。

## 本章脉络

```text
六要素（会计对象的分类）
  ├─ 财务状况要素（静态）：资产、负债、所有者权益
  │    └─ 构成静态等式：资产 = 负债 + 所有者权益 → 资产负债表
  └─ 经营成果要素（动态）：收入、费用、利润
       └─ 构成动态等式：收入 − 费用 = 利润 → 利润表
```

## 反映财务状况的要素（静态，资产负债表要素）

**资产**：由企业**过去的交易或事项**形成的、由企业**拥有或控制**的、**预期会给企业带来经济利益**的资源。

- 确认条件（在符合定义的基础上）：① 经济利益**很可能**流入企业；② 成本或价值能够**可靠计量**
- 注意"拥有或控制"：不拥有所有权但能控制也可（如以前年度考点的融资租入资产思路），关键看实质

**负债**：由企业**过去的交易或事项**形成的、预期会**导致经济利益流出企业**的**现时义务**。

- 确认条件：① 经济利益**很可能**流出；② 金额能够**可靠计量**
- 现时义务 = 现在已经承担的义务，未来才发生的承诺不算负债

**所有者权益**（股东权益）：企业资产扣除负债后，由所有者享有的**剩余权益**（即净资产）。

- 来源：所有者投入的资本、直接计入所有者权益的利得和损失（其他综合收益）、留存收益（盈余公积 + 未分配利润）

## 反映经营成果的要素（动态，利润表要素）

**收入**：企业在**日常活动**中形成的、会导致所有者权益增加的、与所有者投入资本**无关**的经济利益的总流入。

**费用**：企业在**日常活动**中发生的、会导致所有者权益减少的、与向所有者分配利润**无关**的经济利益的总流出。

**利润**：企业在**一定会计期间**的经营成果，包括收入减去费用后的净额，以及直接计入当期利润的利得和损失（营业外收支等）。

::: warning 易错点
- "日常活动"是收入和费用的关键词：出售固定资产、接受捐赠等**非日常**形成的属于**利得/损失**，不是收入/费用。
- 利得和损失有两个去向：直接计入**当期利润**的（营业外），和直接计入**所有者权益**的（其他综合收益）。
:::

## 会计等式

| 等式 | 性质 | 用途 |
| --- | --- | --- |
| **资产 = 负债 + 所有者权益** | 静态等式，反映某一时点的财务状况 | 复式记账法的理论基础，编制**资产负债表**的依据 |
| **收入 − 费用 = 利润** | 动态等式，反映一定期间的经营成果 | 编制**利润表**的依据 |

任何经济业务的发生，都不会破坏会计等式的平衡关系（只会引起等式两边同增同减，或一边内部有增有减）。
