# 基础概念

> 备考层级：初级会计（本笔记）、中级会计、注册会计师。

## 会计的定义

- 属于经济管理活动
- 以货币为主要计量单位
- 有专门的方法和程序
- 核算并监督企业、行政、事业单位的账务
- 反映管理层受托责任履行情况、提供有用经济信息，帮助财务报告使用者作出经济决策

## 会计的职能

| 类别 | 具体职能 | 备注 |
| --- | --- | --- |
| 基本职能 | 核算、监督 | 会计核算是会计监督的基础，会计监督是会计核算的保障。 |
| 拓展职能 | 预测、决策、评价 |

::: warning 注意 
核算的流程：确认 → 计量 → 记录 → 报告
:::

## 会计目标与信息使用者

会计目标：提供会计信息，主要包括**财务状况、经营成果、现金流量**三方面。

会计信息使用者：投资人、债权人、政府及其有关部门、社会公众。

::: tip 待弄清
受托责任与「所有权和管理权分离」之间的关系，目前还不太确定。
:::

## 会计基本假设

会计核算的前提，共四项：

| 假设 | 说明 |
| --- | --- |
| 会计主体 | 核算的空间范围 |
| 持续经营 | 核算的时间范围 |
| 会计分期 | 划分会计期间，形成当期与其他期间的差别 |
| 货币计量 | 以货币作为统一计量尺度 |

::: warning 易错点
会计主体 ≠ 法律主体（法人）。法人一定是会计主体，但会计主体不一定是法人。
:::


## 会计核算的基础

有了会计分期，才产生当期与其他期间的差别，从而形成**权责发生制**与**收付实现制**两种会计基础。
