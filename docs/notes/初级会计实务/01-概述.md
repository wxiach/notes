七个问题串起全章：先搞清楚会计**是什么、干什么、为谁服务**，再解决**前提、规则、标准**三个技术问题，最后落到**对人的要求**。

## 概念与特征

**会计**：以货币为主要计量单位，采用专门的方法和程序，对企业和行政、事业单位的经济活动进行完整的、连续的、系统的核算和监督，以提供经济信息和反映受托责任履行情况为主要目的的经济管理活动。

三个特征：

- 以**货币**为主要计量单位（实物量、劳动量为辅）
- **准确完整性、连续系统性**地记录经济活动
- 属于**经济管理活动**，本质是一种管理工具

## 职能

| 类别 | 具体职能 | 说明 |
| --- | --- | --- |
| 基本职能 | **核算**、**监督** | 核算是监督的基础，监督是核算质量的保障 |
| 拓展职能 | 预测经济前景、参与经济决策、评价经营业绩 | 在基本职能之上延伸 |

::: warning 注意
核算（反映）的流程：**确认 → 计量 → 记录 → 报告**。顺序不能乱，考试常考排序。
:::

## 目标

向财务报告使用者提供会计信息，主要包括企业的**财务状况、经营成果、现金流量**。

会计目标包含两层观点：

1. **受托责任观**：反映企业管理层受托责任的履行情况
2. **决策有用观**：帮助财务报告使用者作出经济决策

::: tip 解惑：受托责任与两权分离的关系
现代企业中**所有权与经营权分离**：股东（所有者）出资但不直接经营，把资源委托给管理层打理。既然"出钱的人"和"管钱的人"不是同一批人，管理层就有义务向所有者汇报"钱管得怎么样"——这就是**受托责任**。会计正是履行这一报告义务的工具，由此产生"受托责任观"；而所有者、债权人拿到报告后要据此做决策，又产生"决策有用观"。所以两权分离是受托责任存在的前提。
:::

## 基本假设

| 假设 | 说明 | 要点 |
| --- | --- | --- |
| 会计主体 | 核算的**空间**范围：为谁记账 | 明确核算对象，区分企业自身与股东个人、本企业与其他企业的交易 |
| 持续经营 | 核算的**时间**范围：假定企业会一直经营下去 | 是会计分期、历史成本计价等的前提 |
| 会计分期 | 将持续经营划分为若干连续、相等的期间 | 由此产生当期与其他期间的差别，进而产生权责发生制与收付实现制 |
| 货币计量 | 以货币作为统一计量尺度 | 隐含币值稳定假定 |

::: warning 易错点
会计主体 ≠ 法律主体（法人）。**法人一定是会计主体，但会计主体不一定是法人**。
反例：企业内部独立核算的分厂、车间，以及由若干法人组成的企业集团（编制合并报表时）都是会计主体，但都不是法人。
:::

## 核算基础

| 对比项 | 权责发生制（应计制） | 收付实现制（现金制） |
| --- | --- | --- |
| 确认标准 | 以收入和费用**实际归属期间**为准 | 以现金**实际收付**为准 |
| 核心思想 | 无论钱是否收付，"属于谁的期间就记在谁的期间" | 见钱才算数 |
| 举例 | 12 月销售、次年 1 月收款 → 收入记在 12 月 | 同一笔业务 → 收入记在次年 1 月 |
| 适用范围 | **企业会计**；政府会计中的**财务会计** | 政府会计中的**预算会计** |

## 信息质量要求

会计信息是为**使用者**（投资者、债权人、政府及其有关部门、社会公众等）的决策服务的，因此必须满足以下八项质量要求。常考"给出例子判断属于哪一项"：

| 要求 | 含义 | 典型例子 |
| --- | --- | --- |
| 可靠性 | 以实际发生的交易为依据，真实可靠、内容完整 | 不做假账 |
| 相关性 | 信息与使用者的经济决策相关 | 提供对预测、评价有用的信息 |
| 可理解性 | 清晰明了，便于理解和使用 | 报表项目分类清楚 |
| 可比性 | 同一企业不同时期可比；不同企业相同期间可比 | 会计政策**不得随意变更**（可变更≠随意变更） |
| 实质重于形式 | 按交易的**经济实质**而非法律形式核算 | 售后回购不确认销售收入 |
| 重要性 | 反映所有**重要**的交易或事项 | 重要项目单独列报，次要的可合并简化 |
| 谨慎性 | 不高估资产或收益，不低估负债或费用 | 计提资产减值准备、坏账准备 |
| 及时性 | 及时确认、计量、报告，不得提前或延后 | 按期结账出报表 |

## 职业道德

财政部《会计人员职业道德规范》概括为"**三坚三守**"：

| 规范 | 定位 | 内涵 |
| --- | --- | --- |
| 坚持诚信，守法奉公 | **自律**要求 | 牢固树立诚信理念，以诚立身、以信立业；严于律己、心存敬畏 |
| 坚持准则，守责敬业 | **履职**要求 | 严格执行准则制度，保证会计信息真实完整；勤勉尽责、爱岗敬业 |
| 坚持学习，守正创新 | **发展**要求 | 秉持专业精神，持续提升专业能力；适应新形势新要求，开拓创新 |
